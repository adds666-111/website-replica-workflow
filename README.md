# 网站复刻与独立审核工作流

提交原站网址，建立页面与交互清单，由实现任务生成代码和预览，再用桌面/手机对照图进行独立审核。

## 提交任务

打开 Issues → New issue → Website parity task，填写原站网址、目标项目和要求。

## 当前状态

- 公开接单仓库和网址表单已配置。
- AI 引擎与服务器执行器尚未接入，提交任务目前只会建立 Issue，不会自动复刻网站。
- 尚未启用自动发布、后台浏览器操作或任何有费用的 AI 调用。

## 计划流程

网址任务 → 原站证据与路由清单 → 实现分支和预览 → 独立截图及交互审核 → 修正 → PR → 人工审核发布。

桌面视口为 1440×1000，手机视口为 390×844。未检查或仍有差异的页面必须标为未完成。

## 执行环境

准备使用专用服务器运行执行器。入门机器先限制为一次一个任务，其余任务排队。需要操作 AdsPower 时使用带桌面的受支持系统。

请勿将密码、代理凭据、店铺登录、API 密钥或浏览器资料提交到公开 Issue 或代码中。执行器不会直接信任并执行任意访客提交的指令。
